>   * 字体：</br>
>      * [Nerd Fonts - Iconic font aggregator, glyphs/icons collection, & fonts patcher](https://www.nerdfonts.com/cheat-sheet)</br>
>      * [ryanoasis/nerd-fonts: Iconic font aggregator, collection, & patcher. 3,600+ icons, 50+ patched fonts: Hack, Source Code Pro, more. Glyph collections: Font Awesome, Material Design Icons, Octicons, & more](https://github.com/ryanoasis/nerd-fonts)</br>
>   * 字体查看器 nexusfont：</br>
>      * [Simple, easy and well designed softwares](https://www.xiles.app/)</br>

下载任意字体加载即可。2MB 大小即包含全部图标。
不同字体实际显示效果有差异，可以加载查看后进行选择。

* VS Code 设置显示字体：
  * 设置字体：`"editor.fontFamily": "'Inconsolata Nerd Font Mono', '...'"`
  * 安装字体之后需要完全退出再重启的方式才能加载字体。
